AGREGAR A STEAM / ADD TO STEAM — Fragile Dreams: Farewell Ruins of the Moon
================================================================

ES
1. Instala el juego con su instalador (o ten ya tu carpeta del launcher).
2. Copia AGREGAR_A_STEAM.bat, AGREGAR_A_STEAM.ps1 y la carpeta "arte" DENTRO de la carpeta del juego
   (la que contiene la carpeta "launcher"). Si lo ejecutas desde otro lugar, te pedira elegir FragileDreams.exe.
3. Doble clic en AGREGAR_A_STEAM.bat. Si Steam esta abierto se cierra solo; luego abrelo de nuevo.
4. El juego aparece en tu Biblioteca con portada, fondo, logo e icono. Funciona con cualquier usuario de Steam
   del PC. Si ya estaba agregado, solo se actualiza (no pierdes el tiempo jugado). Se guarda una copia de
   shortcuts.vdf como shortcuts.vdf.antes_launchers.
Si el mando no responde: Steam > clic derecho al juego > Propiedades > Mando > "Desactivar Steam Input".
Si mueves la carpeta del juego, vuelve a ejecutarlo.

EN
1. Install the game with its installer (or have your launcher folder ready).
2. Copy AGREGAR_A_STEAM.bat, AGREGAR_A_STEAM.ps1 and the "arte" folder INTO the game folder
   (the one that contains the "launcher" folder). If you run it from elsewhere it will ask you to pick FragileDreams.exe.
3. Double-click AGREGAR_A_STEAM.bat. If Steam is open it is closed automatically; start it again afterwards.
4. The game shows up in your Library with cover, background, logo and icon, for every Steam account on the PC.
   If it was already added it is only updated (play time is kept). A backup shortcuts.vdf.antes_launchers is made.
If the controller does not respond: Steam > right-click the game > Properties > Controller > "Disable Steam Input".
Run it again if you move the game folder.
