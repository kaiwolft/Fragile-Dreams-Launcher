INSTALACION EN LINUX (Debian 12, Ubuntu 22.04, Mint 21, Fedora 36 o mas nuevos; 64 bits)
  1. Ten unos 6 GB libres y tu copia europea (.rvz, .iso, .wbfs, .wia o .gcz).
  2. Instala TU PROPIO Dolphin (recomendado el Flatpak):
       sudo apt install flatpak
       flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
       flatpak install flathub org.DolphinEmu.dolphin-emu
  3. Da permiso de ejecucion y abre el AppImage:
       chmod +x Instalar_Fragile_Dreams-x86_64.AppImage
       ./Instalar_Fragile_Dreams-x86_64.AppImage
     Si no abre: sudo apt install libfuse2   o   ./Instalar_Fragile_Dreams-x86_64.AppImage --appimage-extract-and-run
  4. Elige idioma, acepta el aviso, elige tu copia (R2GP99) y tu Dolphin, y pulsa INSTALAR (por defecto ~/Games/Fragile Dreams).
  Diferencias con Windows: en Linux el juego corre en tu Dolphin. El motor propio de Windows (camara con stick derecho y
  raton, 60 FPS) no esta disponible; el movimiento 360, el mando clasico, los botones de Xbox/teclado, el menu de pausa
  y los logros si.
  Si el mando no responde bien: abre Dolphin, configura el mando una vez y en el launcher pon Controles automaticos = No.
  Si algo falla: envia instalacion.log (carpeta de instalacion) o launcher/data/launcher.log.
